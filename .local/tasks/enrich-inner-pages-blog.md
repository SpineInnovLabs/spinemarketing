# Enrich Inner Pages & Blog

## What & Why
Apply UI richness from the Framer reference sites (arvio.framer.website and agent.framer.wiki) to all inner pages and the blog. The first task handles shared components; this task focuses on page-specific content sections that aren't shared — the unique hero/content areas of Product, Platform, Solutions, Pricing, About, Contact, and all solution sub-pages, plus a full blog redesign with richer card layouts and improved reading experience.

**Reference screenshots:**
- `attached_assets/screenshots/arvio_framer_website.png`
- `attached_assets/screenshots/agent_framer_wiki.png`

**Important:** Keep IntegrateWise branding. Adapt visual patterns (card depth, section rhythm, typography hierarchy, interactive elements) from the references, not the branding.

## Done looks like
- Product, Platform, and Solutions pages have richer hero sections and page-specific content areas — better visual hierarchy, card treatments, and section transitions
- Pricing page has an enhanced hero and comparison table with improved styling
- All solution sub-pages (by role, industry, function) have consistent, polished layouts
- Blog listing page has richer post cards with hover effects, featured post treatment, and category filtering visual
- Blog post pages have improved reading experience — better typography, styled blockquotes, code blocks, and a polished article layout
- About, Contact, Why, and other supporting pages have consistent visual polish
- All pages feel cohesive with the enriched shared components from the first task

## Out of scope
- Shared components (header, footer, pricing cards, testimonials, etc.) — handled in the first task
- Adding new blog content or changing existing copy
- Adding new pages or routes

## Tasks
1. **Enrich Product page content section** — improve the hero area and product-specific content layout with better card depth, icon treatments, and visual hierarchy inspired by Agentix's feature sections.
2. **Enrich Platform page content section** — upgrade the platform hero and architecture visualization areas with richer styling.
3. **Enrich Solutions hub and all sub-pages** — improve the solutions directory layout and ensure all 15+ sub-pages (by role, industry, function) have consistent, polished card layouts and hero treatments.
4. **Enrich Pricing page-specific components** — upgrade the pricing hero, comparison table, trust bar, and FAQ with richer visual treatments.
5. **Redesign Blog listing page** — add featured post hero card, richer post cards with image placeholders, category tag pills, better grid layout, and hover animations inspired by Arvio's clean card style.
6. **Redesign Blog post reading experience** — improve article typography, add styled pull quotes, better heading hierarchy, reading progress indicator, and related posts section at the bottom.
7. **Polish remaining pages** — About, Contact, Why, Docs, Changelog, and legal pages get consistent visual treatment matching the enriched design system.
