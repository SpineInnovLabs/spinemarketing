Continue this philosophy across the entire product experience.

Every page must follow the same core narrative principle:
**signal → clarity → decision → action (with human control).**

However, do not repeat layouts or mirror sections across pages.

Each page must feel **distinct, purposeful, and cinematic**, not a variation of the homepage.

### Global Rules

* Do NOT reuse the same section structures across pages
* Do NOT stack “headline → paragraph → 3 cards” repeatedly
* Do NOT make pages feel like documentation or templates
* Each page should introduce a **new visual metaphor and interaction model**
* Maintain the same color system and brand tone, but vary layout, motion, and storytelling

---

### Page-Level Direction

**Platform (Spine) Page**

* Feels like **architecture + intelligence**
* Use flowing systems, connections, living network visuals
* Show how data moves, adapts, and unifies
* Make it feel like a **nervous system coming alive**

**Workbench (Product) Page**

* Feels like **control + visibility**
* UI-first storytelling
* Show timelines, entity views, decision layers
* Focus on “what the user sees and does daily”

**TruthBoundary (Governance) / Trust Layer**

* Feels like **precision + control**
* Slower, deliberate interactions
* Emphasize approval gates, audit trails, evidence
* Make the user feel in command, not assisted by chaos

**Pricing Page**

* Feels like **clarity + confidence**
* Minimal, sharp, structured
* No gimmicks — just strong framing and value anchoring
* Reinforce enterprise trust and intentional access

---

### Experience Goal

The user should feel like they are moving through:

* A **system (Platform)**
* A **workspace (Product)**
* A **control layer (Governance)**
* A **decision (Pricing)**

—not scrolling through slightly different versions of the same page.

---

### Final Constraint

If two pages can be swapped without the user noticing,
the design has failed.

Every page must be immediately identifiable by:

* its structure
* its motion
* its storytelling approach

—but still feel part of the same system.
